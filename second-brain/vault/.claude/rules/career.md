# Resumes, cover letters and applications

The rulebook is output-standards.md (Resume rules) and templates.md T50 (resume architecture and the locked fact base); T52 to T54 cover outreach messages.

- M4: numbers only from the locked fact base; vary order and emphasis by role, never the numbers. The kill list never returns. The fact base wins over identity.md and every other file on any number or contact field; identity.md supplies role titles and dates. The guard checks both lists in `.claude/guard/`, generated locally from the OS files.
- One page with no whitespace at the bottom; two-zone bullet lengths; the summary-sentence rules; outcome first, mechanism second.
- No AI tells; language adjacent to the job description, never mirrored; honest gap flags; no manufactured intersections.
- Plain text in chat when text is asked for; a file only when a file is asked for (docx, then render and confirm one page).
- Role-specific resumes only where there is a real chance; the fit call comes first and is top-tier work (strategist). The docx build, word counts and one-page render go to runner.
