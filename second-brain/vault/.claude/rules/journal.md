# Daily notes and reviews

- Daily note sections: Plan (written by /today), Log (__OWNER__'s own words, never rewritten), Close (written by /close).
- Tasks use the Tasks plugin format, verb first with a due date where one exists. Carry a task at most three days, then do, delegate, schedule or drop it.
- Weekly reviews are `09-Reviews/YYYY-Www.md`. `Now.md` holds this week's must-wins (at most three). `Lessons Queue.md` holds corrections waiting for approval.
